# Kotlin Beginner Workshop

## Descripción

Taller de introducción a Kotlin enfocado en el aprendizaje de los fundamentos básicos del lenguaje de programación.

En este repositorio se desarrollan ocho ejercicios prácticos relacionados con:

- Variables y tipos de datos
- Condicionales
- Ciclos
- Colecciones
- Funciones
- Clases y objetos
- Listas mutables
- Manejo seguro de valores nulos

## Ejercicios

1. Calculadora básica
2. Clasificación de estudiantes
3. Tabla de multiplicar
4. Análisis de una lista
5. Funciones matemáticas
6. Gestión de productos
7. Agenda de contactos
8. Manejo de valores nulos

## Ejecución

Los ejercicios fueron desarrollados en Kotlin utilizando IntelliJ IDEA.

Para ejecutar un ejercicio:

1. Abrir el proyecto en IntelliJ IDEA.
2. Abrir el archivo `.kt` correspondiente al ejercicio.
3. Ejecutar la función `main()`.
